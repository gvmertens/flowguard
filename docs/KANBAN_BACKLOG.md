# Backlog do GitHub Project

Crie um Project do tipo **Board** com colunas **Backlog**, **Em andamento**, **Em revisão** e **Concluído**. Crie uma Issue por linha e relacione a branch e o PR correspondente usando `Closes #N`.

| Card | Resultado de aceite | Branch |
| --- | --- | --- |
| Definir escopo e arquitetura | Carta, diagrama e cenários revisáveis | `docs/arquitetura` |
| Implementar grafo LangGraph4j | State, fork, condição e parada funcionais | `feature/langgraph-agente` |
| Integrar GitHub API | Payload validado, timeout e fallback | `feature/tool-github` |
| Criar contexto/RAG | ADRs, chunks e recuperação documentados | `feature/memoria-contexto` |
| Aplicar governança | Injection bloqueada e aprovação humana | `feature/governanca` |
| Instrumentar observabilidade | Log JSON, auditoria e métrica de latência | `feature/observabilidade` |
| Desenvolver QA inteligente | Review de IA e testes E2E priorizados | `feature/qa-inteligente` |
| Configurar CI e anomalias | Lint, testes, package e análise de risco | `feature/devops-anomalias` |
| Conectar n8n | Webhook, alerta/Issue e reprodução | `feature/low-code` |
| Preparar README e vídeo | Evidências e roteiro final | `docs/readme-video` |
