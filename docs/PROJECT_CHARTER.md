# Carta do projeto - FlowGuard

O FlowGuard reduz incerteza de entrega ao correlacionar sinais que normalmente ficam separados: mudança proposta, resultado do CI, contexto técnico e histórico de incidentes. É um sistema híbrido: IA classifica e explica em um contrato estruturado; regras Java determinísticas validam entrada, ferramentas, autonomia e parada.

Critérios de sucesso: saída rastreável, nenhum side effect diante de risco alto ou input hostil, e reprodução local sem credenciais.
